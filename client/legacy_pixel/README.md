# Legacy art systems (inactive)

The SSF2-style pixel-art pipeline and the earlier vector "toon" roster renderer, retired by the
hand-drawn ink conversion (docs/INK_ART_SPEC.md, docs/INK_MIGRATION.md). Godot ignores this
folder (`.gdignore`), so nothing here is loaded, exported or compiled. It is kept only until the
replacement is verified, then deleted (git history and the `pre-ink-art` tag keep everything).
