# Course Manifest

These are the six main courses as implemented (`client/data/courses/*.json`, authored in `tools/courses/<id>.py`). This file is generated by `tools/courses/manifest.py`.

Every hole is completed by the solver bot with the plain ball and no spin (`client/tests/test_playable.gd`). It also passes the geometry and random-shot robustness checks (`client/tests/test_sim.gd`).

## Reference fidelity

The six courses follow the order and themes of Super Stickman Golf 3's first six courses: Golf Land, Beach Land, Sticky Zone, Snow Field, Gravity Lab and Spin Land (`docs/COURSE_REFERENCE.md` records the research).

- **Pars.** Beach Land uses SSG3's verified per-hole pars. SSG3's pars for Sticky Zone, Snow Field, Gravity Lab and Spin Land are not available, so those are design pars (`"parSource": "design"` in the data), set so a near-perfect player finishes about one under per hole, as SSG3's medals (bronze par, silver -5, gold -10) imply.
- **Layouts.** SSG3's hole geometry is not available (and is the developer's proprietary work), so every layout is original. Each course is built around its SSG3 mechanic, and keeps the verified per-hole details listed below.
- **Attached terrain.** Rebuilt courses are built with `strict=True`: every platform, ceiling and ledge must connect to the ground (`lib.check_attached`), outlines may not fold back, and floating decor types are refused. Ceilings are overhangs from a cliff or wall; lab ceilings rest on the room's walls.
- **Records.** Each rebuilt course has `"layout": 2`. Solo bests and medals from the old layouts are archived under `legacy` in the player's records, not compared with the new holes; completion (ball unlocks) carries over.

## Course data per hole

Each hole has:
- tee spawn (up to 6 balls are spread across it automatically, or placed by an optional `spawns` list);
- cup;
- bounds (camera limits and out of bounds);
- terrain polygons with per-edge materials;
- hazard zones (water, acid, lava);
- gravity fields;
- decor;
- par;
- designer notes.

Moving obstacles are not implemented yet; no hole uses them.

## Tools

- `python tools/courses/check.py <course> [--hole N] [--out DIR]`: rebuild a course and render review maps with the solver's shot paths (headless).
- `tests/ace_search.gd`: fine sweep of tee shots that hole in one (`--only <material>` restricts contact).
- `tests/no_touch_check.gd`: proves a hole can be finished without touching a material.
- `python tools/courses/manifest.py`: regenerates this file.

## Not yet done

- **Collectibles.** There are no optional collectibles or alternative objectives yet. The format can carry them.
- **SSG3 geometry.** Layouts are original (see Reference fidelity). Exact SSG3 holes would need authorised reference material for every hole.
